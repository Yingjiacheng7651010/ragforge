# RAGForge · 工程化企业级 RAG 平台

> 一份以「字节跳动 Agent/LLM 应用工程师」标准设计的 RAG 项目完整规划。
> 目标：**可评估、可观测、可灰度、可写进简历**，而非又一个"向量库 + LLM"的 Demo。

---

## 这是什么

这是一套**项目设计与落地规划文档**，用大厂工程思维把一个 RAG 系统从"想法"拆到"可直接让 Flash/Cursor 生成代码"的粒度。它包含：

- 系统架构与技术选型（含选型理由）
- 16 个模块的详细设计（接口、数据结构、关键算法）
- 15 个**完整可用的 Prompt**（系统/改写/HyDE/自评/生成/评估/护栏…）
- 工程化规范（类型、DI、日志、CI/CD、可观测）
- 评估体系（指标、黄金集、离线/在线、A/B）
- 18 段**可直接投喂 Flash 的生成提示词**
- 7 阶段实施路线图
- 简历包装与面试问答

## 快速上手（3 步）

1. **读**：`00 → 01`，建立全局认知。
2. **动手**：打开 `06-Flash生成提示词.md`，从 `F01` 开始逐段投喂 Flash 生成代码，按 `07` 的里程碑推进。
3. **验证**：跑到 **Phase 4（评估基线）** 后，用真实指标回填 `08` 里的数字，再写进简历。

## 一句话记住核心方法论

> **没有评估的 RAG 优化都是玄学；没有可观测的生产系统都是黑盒；没有降级的高可用都是裸奔。**

这三句话，就是本项目区别于所有"RAG 教程"的地方，也是面试时最有力的总结。
